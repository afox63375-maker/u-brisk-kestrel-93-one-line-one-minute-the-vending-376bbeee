# The Vending Machine Pickup Line

One original pickup line, spoken by a vending machine to a passing human:

> "I've dropped snacks for a thousand strangers, but you're the first one I'd jam my own coil for."

The machine has dropped a snack for every stranger who ever fed it a coin — but this passerby is the first one worth breaking itself for. The joke turns on the coil: the part of the machine that does the dropping, deliberately jammed by the machine itself as its idea of devotion.

`main.py` (Python standard library only) writes the line to `entry.txt` under `MAKEFUN_OUTPUT_DIR` (default `/output`), checks it is a single line of 1–200 characters, reads the file back, and verifies it byte-for-byte with no trailing newline.
